YouTube Trending Video Analysis 


 Project Overview

This project analyzes YouTube Trending Videos to discover patterns in views, likes, dislikes, comments, publishing time, and other factors that influence video popularity.
The analysis is performed using Python and Jupyter Notebook, with data visualization to present meaningful insights.

Objectives

•	Analyze the most viewed YouTube videos. 
•	Identify videos with the highest likes and comments. 
•	Understand the relationship between views, likes, and comments. 
•	Analyze video publishing patterns. 
•	Explore common trends in YouTube video data. 
•	Create visualizations to communicate insights clearly. 

 Dataset

The dataset contains information about YouTube trending videos, including:
•	Video title 
•	Video_id
•	Publish country 
•	Week/day 
•	Tags 
•	Views 
•	Likes 
•	Dislikes 
•	Comment count 
•	Comments disabled 
•	Ratings disabled 
•	Video error/removed status
